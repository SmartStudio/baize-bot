# 白泽桌面端

登录后先通过 `/api/me` 核对账号。本机凭据的 `ownerId` 与当前账号一致时复用 token；切换账号或读取没有 `ownerId` 的旧凭据时，先停旧代理，再重新配对并保存当前账号 id。启动时尚未核对登录账号，仍直接使用已存凭据启动代理，账号归属在下次登录时核对。

被另一台 Mac 顶号后，本机代理停止，凭据删除；删除失败时尝试覆盖为失效标记，文件系统错误只写日志，照常显示顶号提示。若删除和覆盖都失败，当前进程仍不会复用旧凭据，但无法保证重启后的磁盘凭据已经失效。

顶号提示中的「在这台 Mac 上重新连接」会等待在途配对完成，再检查当前凭据是否已经在线。已在线则直接结束；前一次配对取消或失败，则继续带确认配对。控制面在返回新 token 前已经关闭旧连接，因此确认配对后存盘失败无法保住旧连接；本机随后收到 displaced 时显示「凭据保存失败，请重新登录」。

控制面以 4003 拒绝这一版代理时，代理输出 `upgrade_required` 后自己停机。桌面提示「这台 Mac 上的白泽版本太旧，控制面不再接受它连接，请更新白泽」，打包版带「检查更新」按钮；凭据保留，不自动配对或重启，装好新版后照常复用。
