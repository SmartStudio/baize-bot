Bot 的事在 Bot 页，你的事在设置

设置里只放跟你这个人有关、对所有 Bot 都生效的东西。和某个 Bot 有关的，都在它自己的资料页，分享时一起打包。

放在哪有什么为什么放这
Bot 页打开是对话。「它知道的」里是记住的、会做的事、插件、例行。「编辑」里是名字、标签、描述，都可以不填这些跟着 Bot 走，分享出去就是这一份
侧栏「例行」按项目分组的定时活，暂停、恢复、试跑例行为项目的目标服务，项目停了它也该停
设置通用、账号与电脑、插件库、用量、数据与隐私对所有 Bot 生效，改一次就够。账号本来就绑在电脑上，合成一页
不露出来模型、提示词、MCP 配置插件页「高级」里才有，平时用不上

交互上的几条规矩

  • 一句话派活。首页顶上就是输入框，对主助理说。不用先选 Bot、先建群。
  • 一句话建项目。侧栏「项目」旁的加号，说想做成什么事。主助理把队伍、账号、节奏排成一张方案卡，你点开始。
  • 在项目里说，就留在项目里。项目页有自己的输入框和「等你」，不用跳回主助理的对话去找。
  • 草稿就地改。改完直接批。你改过的地方它记下来，写进品牌手册，下次照着写。
  • 批准带范围。批一份计划后，按计划发出的每一条不再问。内容被改动过，就重新问你。
  • 有些事永远问。花钱、改密码或绑定、授权第三方应用、删除你的文件。账号权限开到最大也一样。
  • 登录交给你。它打开助理浏览器的登录页，你扫码或输二次验证。密码不经过模型。
  • 加人要你点头。长期队员由主助理提议、你在建队卡上确认。临时帮手不问，用完就散。
  • 教一个 Bot 就去单聊。它把你说的记成一条，在「它知道的」里能看能删。名字、标签、描述都不用填。
  • 分享的是配方。默认带资料、技能、插件配置和偏好，只和你的号有关的偏好自动留下。登录、对话和你电脑上的文件永远不带。导入后两边各走各的，不同步。
  • 例行跟着项目走。在对话里说一句，确认卡上点头就加上。连续 3 次没人看，它自己停，等你回来问你。

结论

  1. 在这个仓库里原地转向。控制面、电脑代理、Pi 运行器这条链路和个人助理要的形状一致，约 1.3 万行源码和四百多条测试大部分能留。要换的是产品层。
  2. 第一阶段只做运营一条线，只服务你一个人。验收剧本是「用白泽推广白泽的开源仓库一周，你只碰三次」。
  3. 娱乐排在运营之后，德州先于剧本杀。两者都要群里的私密信息。德州规则确定、好验证。剧本杀的难点在剧本内容。
  4. 确认模型是核心，按 Muse 的做法重做。一道统一的闸门判定放行、询问或拒绝，授权带范围，对外发布以可编辑草稿确认。

现在挡路的缺口

前五条是正确性问题，方向怎么定都要修。

  1. 每次 run 的花费报的是会话累计值。reporter.ts:84 用 getSessionStats()，会话跨 run 续用后重复计费。读代码确认，还没跑用例复现。
  2. Pi 内置的 bash、write、edit 完全不过审批。
  3. 任何设置改动都整个换运行器，中止所有在跑的活。共 11 处 sendConfig。
  4. 运行器放弃的审批，控制面还显示待批。
  5. 审批卡和工具行显示原始 JSON。
  6. 一人一台电脑写死了，computers.owner_id 唯一。
  7. 没有浏览器工具，账号只能手填 Bearer 头，没有注册接口。

八个产品决定

01首页是「今天」

等你确认、刚做完、在进行、接下来。群列表退到二级。

02主题任务改叫项目

带目标和指标，比如 GitHub 1000 星、每周 3 篇。

03主助理带队，队伍你看得见

派活你不用管。每个项目有谁由主助理提议、你确认，每个 Bot 可以单聊去教。

04所有动作过一道闸

bash、写文件、浏览器、MCP 都过同一个判定。花钱和账号安全永远问。

05开账号就是登录一次

每台电脑一个助理专用 Chrome profile，后台窗口操作，不抢你的鼠标。

06本机加远程，账号绑电脑

国内平台走本机网络出口，GitHub 和 X 放远程，你合盖它照样跑。

07例行挂项目，设置照 Grok 从简

Bot 有标签和一句描述，能分享成配方。设置只有五页，Bot 自己的在 Bot 页的「编辑」里。

08一句话建项目，项目里就地说

新项目只问一句「想做成什么事」，主助理出方案卡。项目页有自己的输入框和「等你」。德州项目直接开桌。

要你拍板的事

  1. 原地转向还是另起仓库。建议原地转向。
  2. 远程服务器放国内还是海外。取决于第一批平台。
  3. 第一批平台。建议 GitHub、X、小红书或公众号各一个。你实际在运营哪几个号？
  4. 游戏的优先级。建议排在运营之后。娱乐同样重要的话，第 3 期可以和第 2 期并行。
  5. 品牌。设计系统 readme 写暖纸色橘色，token 是冷灰加蓝。个人版要不要换主色、要不要字标。
