## 怎么读

一个框是一件事。做完一件事，在框后面写上证据再打勾。证据是一个提交号、一条用例名、一张截图的路径，或者一行命令的输出。有证据才打勾，没有证据的框算没做。

只跑测试不算验证。一个单元要单元、实机、性能三块都打勾才算验完。

每个单元写九块，依次是依赖、文件、做什么、你看到、单元验证、实机验证、性能验证、你来看、合入。「你来看」写了「不用」的单元，协调者验完直接叠到集成分支。其余的等你看过截图和录屏回一句「过」才叠。

实机验证的截图和录屏存在 `.audit/v1/<单元>/` 下。`.audit` 不进 git。`packages/web/e2e/screenshots` 下的改动是测试产物，任何时候都不提交。

单元编号沿用开发计划。P1-13「最小主助理」是本文新加的，理由见「范围和顺序」。C0、W0、C1 是协调者自己做的三个提交，不派面板。

## 范围和顺序

### 和开发计划不一样的四处

1. **主助理提前到第一版。** U1 要求注册时建好主助理，U2 要求主助理出方案卡，U5 要求主助理接首页的话。开发计划把主助理放在 P2-3，第一版就走不通这三个故事。本文加 P1-13，只做注册时建、首页说话进它的单聊、项目群里当首席。建队卡、临时帮手、团队页仍在 P2-3。
2. **周计划例行放进 P1-4 和 P1-9。** U4 的计划卡由周一 09:00 的例行产出。P1-9 建项目时建这条例行，P1-4 让例行产出计划卡。
3. **四条线，不是三条。** 开发计划写控制面和 Web 一条线。第 1 期 Web 的活有首页、项目页、草稿卡、方案卡、账号页、菜单栏页，一条线排不下。C1 把 HTTP 契约先定死，W0 把 Web 按领域拆开，之后控制面线和 Web 线不共享要改的文件，可以并行。
4. **U1 的「和 AI 打一局」按钮第一版不出。** 游戏在第 3 期，按钮点下去没有东西。

## 附录 A 原型证据

**macOS 沙箱，已实测。** 2026-09-25 在 macOS 26.6.2 上用 `sandbox-exec` 跑配置 `(version 1)(allow default)(deny file-read* (subpath 禁区))(deny file-write* (require-all (require-not (subpath 工作目录)) (require-not (subpath "/dev"))))`。禁区的读用 `cat`、base64 编码路径的 `node`（返回 EPERM）、`python`、工作目录里指向禁区的符号链接、嵌套的子 shell 五种方式试，全部被挡。工作目录里的写成功，工作目录外的写被挡。试的过程中踩过一个坑，SBPL 里并列的两个 `require-not` 是「或」，要包进 `require-all`。结论是 bash 跑在系统沙箱里，禁区和写范围由操作系统管，命令解析只决定要不要问。

**Pi 的工具挂起不会自己超时，读代码得出。** `agent-loop.js:492` 等 `beforeToolCall` 时没有竞速，`runner.js:852-866` 没有超时，pi-agent-core 里搜不到 timeout。模型请求的 300 秒空闲超时只管单次请求。所以挂起十分钟再放行，理论上模型能接着跑。P1-3 的用例用 200 毫秒的空闲超时把它钉住。

**`id()` 改泛型，已实测。** 改完七个包 0 个编译错误，`BotId` 赋给 `UserId` 报 TS2322。

**N2 能干净叠上，已实测。** `git merge-tree` 无冲突，cherry-pick 后 control-plane tsc 通过。数据库用例当时 Postgres 没起，没跑。

**外部事实，2026-09-25 查文档得出，没有实测。**

- X 从 2026-02-06 起按用量付费，新开发者没有免费档。发一条 0.015 美元，带链接 0.20 美元。应用所有者读自己的数据 0.001 美元一条。一周十条、每天读一次数据，推算每月约 1.6 到 12 美元。第一版用你自己注册的 X 应用，你既是所有者又是唯一用户，走最便宜的那一档。X 不用改走浏览器。
- 小红书没有个人发笔记的接口，网页端创作平台能发。2026-03-10 起封「AI 托管」账号，到 5 月处置了 120 万个。同一账号网页端只能登一处。
- Chrome 136 起默认数据目录不接受远程调试，而且不报错。用 `--user-data-dir` 指向独立目录是官方做法。本机是 Chrome 153。
- CDP 新建页面默认把窗口带到前台，要带 `background: true`。有人报告 macOS 上窗口最小化或被完全挡住时，点击和输入调用返回成功但没送到页面。
- GitHub 官方推荐 GitHub App 代用户授权。令牌 8 小时过期，刷新令牌 6 个月且只能用一次。X 的访问令牌 2 小时过期，每次刷新返回新的刷新令牌。

**还没证明的，第一版里各有一个框去做。**

- 未签名的 `.app` 能不能用带按钮的原生通知。P1-2 第一个框。
- `sandbox-exec` 的 `(deny network*)` 能不能挡住所有出网方式。P1-3 第一个框。
- CDP 后台窗口在 macOS 上会不会抢焦点、被挡住时丢不丢事件、登录时能不能把 Chrome 带到前台。P1-5 第一个框。
- Linux 上 bubblewrap 能不能做到和 macOS 沙箱一样的三件事。P1-6 第一个框。

## 附录 B 否掉的做法

- **闸门用模型分类。** 规格第五节写了「闸门分类用便宜的模型」。否掉，因为网页里的提示注入同样能骗分类模型。闸门是纯函数加系统沙箱，便宜模型留给巡检和摘要。
- **只靠解析 bash 命令判权限。** `wt/n7-scope` 的禁读黑名单下 `~/.ssh` 照样能读。命令能用变量、编码、符号链接绕过解析，附录 A 里五种绕法都被沙箱挡住，解析挡不住。
- **给模型通用的点击和输入去发帖。** 闸门认不出哪一次点击是「发布」，内容哈希也无从算起。发帖只走草稿加确定性的发布器。
- **GitHub 用细粒度 PAT。** 最快上手，但你要去 GitHub 设置页填表、每年手动换，和 U1「没有要填的表单」冲突。OAuth App 的 scope 太宽，也不用。
- **OAuth 令牌下发到电脑。** 电脑上的 bash 已经证明挡不住所有读法（`ps eww` 那次）。令牌留在控制面，Bot 走账号代理。
- **X 走浏览器。** 开发计划说 API 太贵就走浏览器。按附录 A 的单价，一个人用每月几美元，API 更稳，不用。
- **第 1 期 Web 并在控制面线里。** 见「范围和顺序」第 3 条。
- **草稿状态只用规格的四种。** 发到一半停机时那一行没处落，重起后会重发或丢。加了 `publishing` 和 `failed`。
- **远程电脑上 bash 先放行。** 没有沙箱时禁区只能靠解析，挡不住。bubblewrap 证明前一律问。
