**P0-2 花费按 run 算。** 0.3 人周，运行器。`run_done` 报本次 run 的增量，run 开始时记下累计值，`agent_settled` 时做差。验证是运行器用例「同一个群连发两条，第二次的 token 不含第一次」，改前先看它红。

**P0-3 config 按 Bot 增量对账。** 1 人周，电脑和运行器。代理收到 config 不再整个换运行器。运行器按 Bot 对账，只重建改了的那个 Bot，正在跑的等它跑完再重建。存 skill 只落文件，不重建会话。你看到的是改一个 Bot 的描述，另一个 Bot 手上的活不停。验证是运行器用例「Bot A 在跑时改 Bot B，A 的 run 正常 run_done」「存 skill 后会话文件不变」。

**P0-4 放弃的审批标已失效。** 0.3 人周，全部三条线。运行器因停机、暂停放弃挂起的审批时发上行报文，控制面把那一行改成 `expired`，推 `approval_updated`，Web 上卡片变灰不能点。验证是控制面用例「运行器上报放弃后，点批准返回冲突，卡片状态是已失效」。

### 第 1 期 运营最小闭环

验收是一周推广白泽的开源仓库，U1 到 U9 全部走通，你主动打开 App 不超过三次。

**P1-1 一人两台电脑。** 2 人周，shared、控制面、电脑。`computers` 按 `(owner_id, kind)` 各一行，`kind` 是 `local | remote`。hub 的连接表、宽限计时、收尾链从 owner 换成电脑。`runs` 加 `computer_id`。网关 key 按电脑轮换。派活按账号选电脑，碰某个账号的活只派到它所在的那台，没有账号约束时本机在线派本机，否则派远程。验证是控制面用例「本机和远程同时在线互不顶掉」「本机断线只收尾本机的 run」「同一台电脑的新连接仍然顶掉旧连接」「碰本机账号的活在本机离线时记失败而不是派到远程」。先在 shape 提交里改类型，让编译器指出每一处。

**P1-2 桌面 App。** 1.5 人周，电脑和壳。按 `wt/n8-electron` 的做法收成正式包。一条命令打出能装的 Mac 包，首次登录调 P0-6 的接口注册本机，token 存钥匙串，经 stdin 交给代理。菜单栏常驻，数字只数等你确认的事，下拉能直接批、能说一句。原生通知带「批准」按钮。原生标题栏，字体打包，API 地址可配。`before-quit` 的守卫看 `exitCode` 或 `signalCode`，不看 `killed`。你看到的是 U1 和 U4。验证是在一台没配过 `.env` 的 Mac 上装 App 走通 U1，`ps eww` 看代理进程环境里没有 `AGENT_TOKEN=`。2026-10-13 对过，下拉能直接批已经做了。原生通知上的「批准」按钮在 M4 时去掉，不再做。没配过 `.env` 的 Mac 能直接装，要等签名和公证，并进第 3 期交付补强。

**P1-3 统一闸门。** 1.5 人周，shared、运行器、控制面。按规格第二节「确认与授权」实现判定函数，替掉 `approvalRule`。`approvals` 表加 `action` 和 `grant_id`，新增 `grants` 表。bash 命令先解析出动作类别再判。文件工具按路径判，工作目录之外走 `write_outside`。暂停和接管改成在闸门挂起，删掉 `abandon` 加 `abort()` 和排队重放。验证是运行器用例「bash 跑 curl 往外发时挂起等确认」「spend 类动作带 forever 授权仍然问」「挂起十分钟后放行，模型还能接着跑」，e2e 用例「bash 在工作目录外写文件挂起等确认」「bash 读 `~/.ssh` 被拒绝，授权了也被拒绝」「给过 `~/Downloads` 的读授权后，读那里的文件不再问」。「挂起十分钟」实际用例挂的是 400ms。2026-10-13 起，这条只对你当面发起的审批成立，例行和交接触发的审批 10 分钟按拒绝处理，见第 3 期交付补强。

**P1-4 草稿和内容计划。** 1 人周，全部三条线。`publish` 类动作生成草稿，不弹「允许吗」。草稿卡就地改字。一份计划一次批完，批的是内容哈希，发出时对得上放行，对不上回到待批。你改过的地方记下来，第 2 期进品牌手册。你看到的是 U4、U6。验证是控制面用例「批过的草稿被 Bot 改过后重新待批」，Playwright 走一遍改字加批准。

**P1-5 助理浏览器和账号。** 2.5 人周，全部三条线。每台电脑一个助理专用 Chrome profile，运行器里写 CDP 浏览器工具，参照 `pi-skills/browser-tools`，不走 MCP。账号对象、四档权限、账号页。登录时把窗口弹到前台，你登完退回后台。登录过期只停碰这个账号的活，出「卡住了」通知。第一批平台是 GitHub、X、小红书。GitHub 和 X 走 OAuth，凭据在工具调用时注入，账号放远程。小红书只走浏览器，账号放本机。X 的 API 现在按什么收费、免费额度够不够每周几条，写任务书前先查，不够就也走浏览器。你看到的是 U3、U7。验证是一段录屏，Bot 在后台窗口发一条测试帖，你的鼠标没被抢。运行器用例「浏览器工具的结果里没有 cookie 和密码框内容」。2026-10-15 起，登录不再把窗口弹到前台。登录页在后台开，画面经控制面送到网页上操作，远程电脑也能登小红书、发小红书。Bot 卡住时用 `browser_ask_user` 请你接手同一块画面。设计理由见 `packages/control-plane/README.md` 的「画面面」。

### 第 2 期 小队和主动性

**P2-2 品牌手册。** 1 人周。所有 Bot 共用一份，写产品事实、口吻、禁区、你的素材库。Bot 写每一条内容前先读。P1-4 记下的改动进这里。

**P2-3 主助理和建队卡。** 1 人周。Bot 加角色。注册时建主助理，项目群里它就是首席。建队卡照 `skill_offer`，只问要不要这个人。临时帮手随拉随散，不进团队页，不留记忆。你看到的是 U11。

**P2-4 Bot 页和偏好。** 1 人周。团队页点卡片进单聊，偏好记在单聊里，可看可删。「编辑」弹窗改名字、标签、描述，`Bot.tag` 改成 `tags: string[]`。你看到的是 U12、U13。2026-10-13 起，Bot 记偏好前先出确认卡，你点了才写入，见第 3 期交付补强。

**P2-5 例行挂项目。** 0.5 人周。`routines` 加 `projectId`，`botId` 变成可换的执行者，`enabled` 换成 `on | paused | auto_paused`。连续三次没人看自己停。对话里建、预填改。你看到的是 U10。

**P2-6 分享和导入。** 0.5 人周。模板打包、默认摘要、自己挑、导入即复制。`SkillSource` 加 `template`，偏好加 `private`，插件导出不含凭据。验证是对导出包 grep 不到任何 token、cookie、对话内容。你看到的是 U14。

**P2-7 设置五页和用量。** 0.5 人周。设置收成五页，用量按月、按 Bot，月预算超了先停例行。

### 第 3 期 游戏桌和交付补强

**P3-1 消息可见范围。** 0.5 人周。消息加 `visibleTo`，派活拼上下文按收件 Bot 过滤。验证是控制面用例「牌友 Bot 的 prompt 里没有别人的底牌」。

**P3-2 德州引擎。** 1.5 人周。发牌、底池、行动合法性、结算写在控制面，纯函数，带随机种子可重放。牌力和位置算好再给模型。

**P3-3 牌桌和牌友。** 1 人周起。牌桌页、三个按钮、问老白、换牌友、散场复盘。你看到的是 U15。无真钱，对外前问法务。

剧本杀排在德州之后，先买或改编一两个现成剧本。

P3-4 起是交付补强，把 2026-10-13 定下的八项做成可交付版本，设计和理由在 `plan/交付补强架构.md`。下面按依赖排。P3-5、P3-6、P3-7、P3-14、P3-15、P3-16 互不依赖，形状提交之后可以一起开工。P3-8 和 P3-10 依赖 P3-4，P3-11 依赖 P3-10，P3-12 和 P3-13 依赖 P3-10。

**P3-4 统一可靠信封。** 2 人周。控制面和电脑代理之间的每条报文都带序号，对端确认后才丢，断线重连按序号补发，旧连接的迟到报文按连接代际丢掉。握手带协议版本，低于最低版本的代理收到关闭码 4003 和升级提示。下行加 `cancel`，停掉一个 run 不再要等它自己跑完。你看到的是断网再连上，审批卡、交接卡、发布结果一条不少。验证是 e2e 用例在发出审批请求、交接、发布结果的当口断开代理连接，重连后三张卡都在，且没有重复。

**P3-5 审批规则。** 1 人周。用户在同一 (Bot, 群) 里发来新消息，这个 Bot 在这个群挂着的审批作废。「批准」「拒绝」这类被当成答复吃掉的消息不算新消息。例行和交接触发的审批 10 分钟没人批，按拒绝处理。你当面发起的不过期。草稿和内容计划不受影响。你看到的是审批卡上多了「已作废」和「超时未批，已拒绝」两种结局。验证是控制面用例逐条钉住这三条规则，外加一条「回复批准不会作废自己」。

**P3-6 偏好确认卡。** 0.5 人周。`remember_preference` 不再当场写入，先在群里出一张卡，你点「记住」才进偏好表，点「不用」就丢。卡的样子和流程照抄技能建议卡。验证是运行器用例「调用后偏好表没变」，加控制面和 Web 用例「点记住后偏好随 config 下发」。

**P3-7 MCP 代执行。** 1.5 人周。HTTP MCP 改由控制面去连，凭据不再随 config 发到电脑。运行器调 MCP 工具时把调用转给控制面，拿回结果。连接可以标「只在本机」，这种连接的凭据只发给本机那台电脑，由本机直连。你看到的是工具设置页每个连接多一个「只在本机」开关。验证是控制面用例「远程电脑收到的 config 里没有任何凭据明文」，加 e2e 用例经控制面调通一个假 MCP 服务。

**P3-8 产物附件。** 1 人周。草稿配图、导出文件这类产物上传到控制面，按附件 id 引用。远程起草的配图本机发布时能取到。验证是 e2e 用例远程电脑起草带图，本机发布器拿到同一张图。

**P3-9 串行链按 (Bot, 群)。** 1.5 人周。运行器的串行队列从每个 Bot 一条改成每个 (Bot, 群) 一条。同一个 Bot 可以同时在两个群干活，同一个群里仍一条一条来。暂停仍按 Bot，一停全停。验证是运行器用例「同一 Bot 两个群的 prompt 并行跑完，同一群的两条按序」。

**P3-10 租约和服务器工作记录。** 2 人周。工作记录存服务器，Pi 会话的每一条记录按 (Bot, 群) 追加上传，服务器按序号去重。(Bot, 群) 同一时刻只有一台电脑持有租约，掉线超过宽限期才换手，换手时代际加一，旧代际的追加一律拒收。你看到的是本机掉线后远程接着干，不再分叉。验证是控制面用例覆盖重复追加、跳号、旧代际追加三种情况，加 e2e 用例本机断开后远程接手同一个群。

**P3-11 运行器记录上传和重建。** 2 人周。运行器在每轮结束时把新增记录传上去。拿到租约时如果本地会话比服务器旧或者没有，按服务器记录重建。第一次连上新控制面时，把电脑上已有的会话 JSONL 导成服务器记录，按 (Bot, 群) 幂等，旧文件留着。验证是运行器用例「删掉本地会话目录后重建，Pi 读到的历史和删之前一致」，加导入用例跑两遍结果相同。

**P3-12 留存过滤和连带删除。** 1 人周。上传前把截图原图和超长输出换成摘要。删 Bot、删群时连带删它们的工作记录和附件，删号全删。验证是控制面用例逐条钉住删 Bot、删群、删号后记录表和附件表里查不到残留。

**P3-13 记忆库和 recall。** 1.5 人周。Bot 可以按关键词查自己读得到的历史，查询按收件人过滤，私密消息不进别人的结果。依赖 P3-6 先落地。验证是控制面用例「牌友 Bot 查不到别人的底牌」这一类可见性用例，加运行器用例 recall 工具返回带出处的片段。

**P3-14 目录隔离和共享区。** 1 人周。Mac 上的 seatbelt 改成只放行本 Bot 的目录和用户级共享区，别的 Bot 的目录读不到。产出物放共享区。设置页写明浏览器登录态是所有 Bot 共用的。验证是 macOS 上真跑 seatbelt 的用例「读别的 Bot 目录被拒，读共享区放行」。

**P3-15 顶号提示。** 0.5 人周。第二台 Mac 配对时先提示「另一台 Mac 会退出」，你确认后才顶。被顶的那台 App 显示「已在另一台 Mac 登录」，不再静默断开。验证是控制面用例「不带确认的配对被拒并说明原因」，加电脑代理用例收到顶号关闭码后不重连。

**P3-16 自动更新和开机自启。** 1 人周。App 启动时查新版本，下载完提示重启。设置里加开机自启开关。验证是桌面用例对一个本地更新源走完检查、下载、提示三步。

**P3-17 签名和公证。** 0.5 人周，排在最后，等 Apple Developer 账号。Developer ID 签名、公证、装订。验证是一台没配过开发环境的 Mac 下载 dmg 直接打开，Gatekeeper 不拦。

## 六、要你拍板的事

1. **原地转向。** 本文按「在这个仓库里原地改成个人助理」排。企业版没对外发过，第一个用户本来就是你们自己。不同意的话，v0.1 的规格和计划从 git 历史取回即可。
2. 2026-09-25 已定四项。第一批平台是 GitHub、X、小红书。远程服务器放海外。bash 边界按规格的四层判定。首页用方案 A「今天清单」。
3. 规格第七节还待定的有六项。品牌、人设文案、模型供应商三项不挡第 1 期，没定之前按默认做。谁是用户、IM 里的多 Bot、第一批业务系统三项是 2026-10-22 随 #71 加的。游戏优先级不用再定，德州已经做了。
4. 2026-10-13 定了交付补强的范围，全部进第 3 期的可交付版本。
   - 统一可靠信封，包括序号、确认、补发、连接代际、版本握手和下行 cancel。
   - 上下文中枢做完整版，以服务器为准。工作记录带 (Bot, 群) 租约，记忆库带 recall，产物附件化。工作记录存服务器，记录层过滤截图原图和超长输出，删 Bot、删群时一起删，删号全删。
   - HTTP MCP 改由控制面代执行，电脑不拿凭据。连接可标「只在本机」，只下发到本机。
   - 审批规则三条。同一 (Bot, 群) 的新消息作废旧审批。例行和交接触发的审批 10 分钟按拒绝处理。运行器串行链改按 (Bot, 群)。
   - `remember_preference` 先出确认卡，先于 recall 落地。
   - 浏览器登录态按人共享并在设置页写明。会话、记忆、技能目录按 Bot 隔离。产出放用户级共享区。
   - 多台 Mac 本次只做顶号提示。
   - 桌面版算交付内容，签名、公证、自动更新、开机自启都做，Apple Developer 账号由你申请。

5. 交付补强里有四处细节先按默认做，你说一声就改。
   - 审批不占租约。挂着审批时本机掉线，宽限期过了审批照现在的逻辑作废，租约照常换手。另一种做法是挂着审批时租约不放，代价是远程在这段时间接不了手。
   - 暂停期间 10 分钟照走。例行和交接触发的审批在 Bot 暂停时也会超时。另一种做法是暂停时冻结计时。
   - 新消息只作废被派活的那个 Bot 的审批，只认你发的消息，被当成答复吃掉的消息不算。作废和你点批准同时发生时，先写进库的算数。
   - 「只在本机」连接的工具结果不存原文，服务器只留工具名、时间、字节数和哈希。另一种做法是多留前 512 字节。

其余都是工程判断，按本文推进。

## 七、怎么协作

- 实现可以派给 codex、grok 或 agy 面板，任务书写 `.audit/briefs/<slug>.md`，报告回 `.audit/reports/<slug>.md`，流程在 `.claude/agents/codex-panel.md`。报告不论谁写，协调者都在工作树里重跑门禁、看过 diff 再合。
- shared 的形状改动由协调者先单独提交，各线再并行。同一期内各线不共享要改的文件。
- 各线验完先叠到一个集成分支，你亲自验过才合 main。
- `packages/web/e2e/screenshots` 的改动是测试产物，不提交。
